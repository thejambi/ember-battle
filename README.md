# Ember Battle (prototype)

A hot-seat web prototype of a co-op card game. Heroes train movesets, then fight villains in step-by-step battles where both sides reveal +, − or • steps at the same time.

Play it: https://thejambi.github.io/ember-battle/

Solo (two lanes) or 2 players taking turns on one device. Card data lives in `cards.js`.
